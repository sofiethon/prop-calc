---
description: Erklärt das Projekt oder eine Datei für Nicht-Programmierer*innen
argument-hint: [Datei oder Thema, optional]
---

Erkläre $ARGUMENTS (wenn leer: das gesamte Projekt) so, als würdest du es einer Produktmanagerin ohne Programmierkenntnisse erklären.

Regeln:
- Deutsch, keine Code-Zitate, keine Dateinamen-Listen ohne Erklärung.
- Nutze die Schichten Frontend / Backend / Datenbank / API / Hosting und sag, welche Teile des Projekts zu welcher Schicht gehören.
- Verwende die Küchen-Metapher (Gastraum = Frontend, Küche = Backend, Vorratskammer = Datenbank, Kellner = API, Gebäude = Hosting), wenn sie hilft.
- Maximal 12 Sätze. Am Ende: eine Sache, die die Person als Nächstes selbst ausprobieren könnte.
